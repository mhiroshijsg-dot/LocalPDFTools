# LocalPDFTools

PDF の**結合・分割・回転・暗号化の解除・圧縮・文字の抽出**を、**あなたの Mac の中だけで**行うアプリです。
ファイルをインターネットに送らないので、成績証明書や身分証明書のような大事な書類も安心して扱えます。

*English: [README.en.md](README.en.md) — A macOS app to merge, split, rotate, unlock, compress, and extract text from PDFs entirely on your Mac. The interface is in Japanese and English.*

---

## できること（バージョン 1.1.0）

1 つの窓に PDF を入れて、やりたい操作のスイッチをオンにし、「実行して保存…」を押すだけです。いくつかの操作を続けて行えます（例：解除 → 回転 → 結合 → 圧縮）。

| 機能 | 内容 |
|---|---|
| **暗号化の解除** | 「開けるけれど印刷やコピーが禁止されている PDF」の制限を外します。開くのにパスワードが要る PDF も、パスワードを入れれば外せます |
| **回転** | ページの縮小表示をクリックして、ページごとに 90° ずつ回します。全ページまとめて回すこともできます |
| **結合** | 複数の PDF を 1 つにまとめます。ドラッグで順番を入れ替えられます |
| **分割** | 1 つの PDF を、いくつかの PDF に分けます。1 ページずつ・N ページごと・範囲を書く・ページを見て切れ目を選ぶ、から選べます。分けた PDF は新しいフォルダにまとめて保存します |
| **圧縮** | ファイルを小さくします。品質（高・中・低）を選ぶだけで使えます。見た目を変えない圧縮はいつも行い、画像の解像度や JPEG の画質を下げる、重いグラフを画像にする、なども選べます。保存する前に、どのくらい小さくなるかを確かめられます |
| **文字の抽出** | PDF の文字を取り出して、コピーしたり .txt に保存したりします。スキャンした PDF は、Mac の文字認識（OCR）で読みます |

解除・回転・結合・分割は、ページを作り直さずに処理します。文字・画質・ファイルの大きさはほとんど変わりません。

使い方の詳しい説明は、アプリのメニューの「ヘルプ」→「LocalPDFTools のヘルプ」（⌘?）で見られます。ヘルプの窓の左上の欄で、説明の中を検索できます。

画面は日本語と英語に対応しています（[画面の言語](#画面の言語)）。

## 動く環境

- **Apple シリコン（M1 以降）の Mac**。Intel の Mac では動きません
- **macOS 14 Sonoma 以降**

## インストール

1. [Releases のページ](https://github.com/mhiroshijsg-dot/LocalPDFTools/releases/latest)から `LocalPDFTools-1.1.0.zip` をダウンロードします。
2. ダウンロードした zip をダブルクリックして展開します。
3. できた `LocalPDFTools` を「アプリケーション」フォルダに移します。

### 最初の 1 回だけ必要な操作

このアプリは個人で作っているので、Apple の審査（公証）を受けていません。そのため、最初に開くと
「“LocalPDFTools”は開かれていません」「Apple は、“LocalPDFTools”に Mac に損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした」
のような表示が出て止まります。次の手順で開いてください。

1. 表示の「完了」を押して閉じます（「ゴミ箱に入れる」は押さないでください）。
2. **システム設定** → **プライバシーとセキュリティ** を開きます。
3. 下の方の「セキュリティ」の欄に「“LocalPDFTools”は … ブロックされました」と出ているので、**このまま開く** を押します。
4. パスワード（または Touch ID）を求められたら入力します。もう一度出る確認で **このまま開く** を押すと起動します。

2 回目からは普通に開けます。

## 使い方

窓は 3 つに分かれています。

- **左「ファイル」**: PDF を窓にドラッグ＆ドロップするか、右上の「＋」（⌘O）で追加します。上から順に並び、行をドラッグすると順番を変えられます。暗号化されている PDF には「制限あり」「要パスワード」の札が付きます。
- **右「やること」**: 行いたい操作のスイッチをオンにします。オンにした操作を、上から順に行います。
- **下**: これから行うことが矢印で表示されます（例：解除 → 回転 → 結合 → 1 つの PDF にして保存）。保存名と保存先を確かめて、**実行して保存…**（⌘S）を押します。

保存するときは毎回、保存場所と名前を聞かれます。**元のファイルは書き換えません**（元と同じファイルを保存先に選ぶと止まります）。

- **結合をオンにしたとき**は、1 つの PDF にして保存します。
- **結合をオフにしたとき**は、ファイルごとに別々に保存します。ファイルごとに保存のダイアログが出ます（初期の名前は、元の名前に `_unlocked`・`_rotated` などを付けたもの）。
- **分割をオンにしたとき**は、保存の場所を 1 回だけ選びます。そこに新しいフォルダを作り、分けた PDF をまとめて入れます。

### 操作の順番
- 回転・結合・分割・圧縮の順番は、**設定（⌘,）**で行をドラッグして変えられます。最初は「回転 → 結合 → 分割 → 圧縮」です。
- 暗号化の解除はいつも最初です。

### 暗号化の解除
- オンにすると、制限のある PDF とパスワードが要る PDF の数を表示します。札にマウスを乗せると、何が禁止されているかが出ます。
- 保護を外す前に、「外して続ける」かどうかを確認します。
- パスワードが要る PDF は、処理の途中でその PDF の番になったときにパスワードを聞きます。入れたパスワードは、この Mac の中で処理に使うだけです。保存も送信もしません。
- 保存する PDF が本当に暗号化されていないかを、アプリが確かめてから保存します。
- 解除も結合もしないで回転や圧縮だけをしたときは、制限を付けたまま保存します（黙って外すことはしません）。
- **自分が権利を持つ書類にだけ使ってください。** 他人の書類や、制限を外すことが許されていない書類には使わないでください。

### 回転
- 「ページを見て回す…」を押すと、入れた PDF のページがすべて並びます。
- ページをクリックするたびに右へ 90° 回ります。右クリックすると、左回り・180°・元に戻すを選べます。
- 上の「すべて左に 90°」「すべて右に 90°」で全ページまとめて回せます。「すべて元に戻す」で最初の向きに戻ります。
- 開くのにパスワードが要る PDF は、ページを表示できないので回せません。

### 結合
- 左の並びの上から順に、1 つにまとめます。
- **しおり（目次）と、PDF の中のページへのリンクは、結合すると消えます**。Web ページへのリンクは残ります。しおりのある PDF を入れると、そのことを知らせます。
- 分割とは同時に使えません（どちらか一方だけをオンにできます）。

### 分割
- 分け方は 4 つです。
  - **1 ページずつ**: 10 ページなら 10 個の PDF にします。
  - **N ページごと**: 3 なら 1〜3・4〜6・… と分けます。最後は余りのページです。
  - **範囲を書く**: `1-3, 4-7, 8-` のように書きます。書いた順に 1 つずつの PDF になります（`8-` は 8 ページから最後まで）。範囲を 1 つだけ書けば、一部のページだけを取り出せます。
  - **切れ目を選ぶ**: 「ページを見て分ける…」でページの縮小表示が並ぶので、ページの間をクリックしたところで切ります。
- 「範囲を書く」と「切れ目を選ぶ」は、PDF が 1 つのときだけ使えます。PDF がいくつかあるときは、それぞれを同じ分け方で分けます。
- 保存すると、選んだ場所に新しいフォルダ（初期の名前は `元の名前_split`）を作り、`元の名前_p1-3.pdf` のような名前で入れます。同じ名前のフォルダが既にあるときは「名前 2」のように番号を付けた新しいフォルダを作ります。
- 保存した後は、作ったファイルの数・合計の大きさ・一番大きいファイルの大きさ・ファイルの一覧を表示します。
- 文字・画質・Web ページへのリンクは変わりません。**しおり（目次）と PDF の中のページへのリンク、編集・印刷などの制限は残りません**（制限のある PDF を分けるときは、実行の前に確認します）。
- フォントや、いくつものページで使う画像は分けた PDF のそれぞれに入るので、合計は元より大きくなることがあります。提出先の大きさの上限は 1 ファイルごとに効くので、「一番大きいファイル」を見てください。圧縮もオンにすると、分けた PDF をそれぞれ圧縮します。

### 圧縮
- ふだんは**品質**を「高・中・低」から選ぶだけです（最初は「高」）。
  - **高**: 300 dpi より細かい画像だけを縮めます。見た目はほとんど変わりません。
  - **中**: 画像を 150 dpi まで縮め、JPEG を画質「中」で保存し直します。画面で読むには十分です。
  - **低**: 画像を 100 dpi まで縮め、JPEG を画質「低」で保存し直します。拡大すると画像の粗さが分かります。
- **詳細**を押すと、次の方法を自分で選べます。
  - **構造の圧縮**（最初からオン）: PDF の中の部品をまとめて圧縮し直します。見た目は一切変わりません。
  - **解像度**: 選んだ dpi（300・200・150・100・72）より細かい画像だけを縮めます。それより粗い画像には触りません。
  - **JPEG の画質**: 写真やカラーのスキャンのような JPEG の画像を、選んだ画質で保存し直します。
  - **図の線を減らす**（matplotlib などで作ったグラフ向け）: 補助グリッド線と補助目盛を消す、曲線の点を間引く、の 2 つです。最初から選ばれていて、減らせる本数を表示します。線を消すと見た目が変わります。
  - **図を画像にする**（最初はオフ）: 点や線がとても多いグラフ（何万点もの散布図など）を、同じ位置・同じ大きさの画像に置き換えます。「図を選ぶ…」で 1 つずつ選べます。図の中の文字は選択・検索できなくなります（本文の文字はそのまま）。
- 次の 4 つは、選ばなくても**いつも行います**（見た目は変わらないか、ほぼ変わりません）。
  - 要らないデータを捨てる（Illustrator などが編集用に入れておくデータ、ページの小さな縮小画像など）
  - 中身がまったく同じ画像・フォントなどの重複を 1 つにまとめる（結合した PDF によく効きます）
  - LaTeX の PDF などに入っている Type1 のフォントを、同じ形のまま小さな形式（CFF）に作り直す
  - カラーで保存されているのに白・黒・灰色しか無い画像を、灰色の画像として保存し直す
- PDF を入れると、圧縮したあとの**目安**を表示します（大きさの内訳は「詳細」の中）。目安は見積もりなので、正確な数字は **試算する** で出します（実際に圧縮して大きさを測り、作った PDF はすぐ消します）。
- **目標**に提出先の大きさの上限（MB）を入れると、収まりそうなら緑、超えそうなら赤で示します。
- 圧縮したら、何をしたか（画像をいくつ縮めたかなど）を表示します。元より大きくなったときは、そのことを知らせます。
- パスワードが要る PDF は、解除するまで中を見られないので、内訳・目安・試算には入りません（圧縮そのものは行います）。

### 文字の抽出
- オンにして「文字を見る…」を押すと、入れた PDF の文字がページごとに並びます。そこでコピーしたり、.txt に保存したりします（全部を 1 つの .txt にまとめる・ファイルごとに保存する、から選べます）。
- パソコンで作った PDF は、中に入っている文字のデータをそのまま取り出します。読み間違いはありません。
- スキャンした PDF のように文字のデータが無いページは、ページの「OCR する」を押すと、Mac に入っている文字認識（OCR）で読みます。日本語と英語を読みます。
- OCR は読み間違えることがあります（ローマ数字・〇・数字など）。提出物に使う前に、元の PDF と見比べてください。
- 読んだ文字を PDF に埋め込むこと（検索できる PDF にすること）はしません。

### 保存名の文字数
- 保存名の横に文字数（`.pdf` を含む）が出ます。「上限」に提出先の決まり（例：50 文字以下）を入れておくと、超えたときに赤字になります。

### 画面の言語
- 画面は日本語と英語に対応しています。最初は Mac の言語の設定に合わせます（日本語でも英語でもない Mac では英語）。
- **設定（⌘,）**の「言語」で、このアプリだけを日本語か English にできます。変えたら、アプリを終了して開き直すと切り替わります。

## プライバシー

- このアプリはインターネットに接続しません。PDF もパスワードも、外に送ることはありません。
- 処理には、アプリの中に入っている [qpdf](https://qpdf.sourceforge.io/) と、macOS に最初から入っている部品だけを使います。

## 開発者向け

必要なもの：

- Xcode 27 以降
- Homebrew の qpdf（`brew install qpdf`）。ビルドのたびに .app に同梱します

`LocalPDFTools.xcodeproj` を開いて ⌘R で起動、⌘U で検査（テスト）が走ります。
コードの構成は [`Sources/README.md`](Sources/README.md) にあります。

画面の文の英訳は `Localizable.xcstrings`（String Catalog）にあります。鍵は日本語の文そのものなので、画面の文はこれまでどおり日本語で書き、英訳を Catalog に足します。
検査は日本語の画面の文を確かめるので、スキームの設定で日本語（`-AppleLanguages (ja)`）で走らせています。

配布用の zip を作るには：

```
scripts/make_app.sh
```

`build/LocalPDFTools.app` と `build/LocalPDFTools-<バージョン>.zip` ができます。
バージョン番号は Xcode のプロジェクトの設定（MARKETING_VERSION）で決まります。
