# LocalPDFTools

PDF の**結合・回転・暗号化の解除・圧縮**を、**あなたの Mac の中だけで**行うアプリです。
ファイルをインターネットに送らないので、成績証明書や身分証明書のような大事な書類も安心して扱えます。

*A macOS app to merge, rotate, unlock, and compress PDFs entirely on your Mac — no uploads. The interface is in Japanese.*

---

## できること（バージョン 0.2.0）

1 つの窓に PDF を入れて、やりたい操作のスイッチをオンにし、「実行して保存…」を押すだけです。いくつかの操作を続けて行えます（例：解除 → 回転 → 結合 → 圧縮）。

| 機能 | 内容 |
|---|---|
| **暗号化の解除** | 「開けるけれど印刷やコピーが禁止されている PDF」の制限を外します。開くのにパスワードが要る PDF も、パスワードを入れれば外せます |
| **回転** | ページの縮小表示をクリックして、ページごとに 90° ずつ回します。全ページまとめて回すこともできます |
| **結合** | 複数の PDF を 1 つにまとめます。ドラッグで順番を入れ替えられます |
| **圧縮** | ファイルを小さくします。見た目を変えない圧縮のほか、画像の解像度や JPEG の画質を下げることもできます。保存する前に、どのくらい小さくなるかを確かめられます |

解除・回転・結合は、ページを作り直さずに処理します。文字・画質・ファイルの大きさはほとんど変わりません。

これから作る予定の機能：

- 文字の抽出（スキャンした PDF の文字の読み取りも含む）

## 動く環境

- **Apple シリコン（M1 以降）の Mac**。Intel の Mac では動きません
- **macOS 14 Sonoma 以降**

## インストール

1. [Releases のページ](https://github.com/mhiroshijsg-dot/LocalPDFTools/releases/latest)から `LocalPDFTools-0.2.0.zip` をダウンロードします。
2. ダウンロードした zip をダブルクリックして展開します。
3. できた `LocalPDFTools` を「アプリケーション」フォルダに移します。

### 最初の 1 回だけ必要な操作

このアプリは個人で作っているので、Apple の審査（公証）を受けていません。そのため、最初に開くと
「“LocalPDFTools”は開かれていません」「Apple は、“LocalPDFTools”に Mac に損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした」
のような表示が出て止まります。次の手順で開いてください。

1. 表示の「完了」を押して閉じます（「ゴミ箱に入れる」は押さないでください）。
2. **システム設定** → **プライバシーとセキュリティ** を開きます。
3. 下の方の「セキュリティ」の欄に「“LocalPDFTools”は … ブロックされました」と出ているので、**このまま開く** を押します。
4. パスワード（または Touch ID）を求められたら入力します。もう一度出る確認で **このまま開く** を押すと起動します。

2 回目からは普通に開けます。

## 使い方

窓は 3 つに分かれています。

- **左「ファイル」**: PDF を窓にドラッグ＆ドロップするか、右上の「＋」（⌘O）で追加します。上から順に並び、行をドラッグすると順番を変えられます。暗号化されている PDF には「制限あり」「要パスワード」の札が付きます。
- **右「やること」**: 行いたい操作のスイッチをオンにします。オンにした操作を、上から順に行います。
- **下**: これから行うことが矢印で表示されます（例：解除 → 回転 → 結合 → 1 つの PDF にして保存）。保存名と保存先を確かめて、**実行して保存…**（⌘S）を押します。

保存するときは毎回、保存場所と名前を聞かれます。**元のファイルは書き換えません**（元と同じファイルを保存先に選ぶと止まります）。

- **結合をオンにしたとき**は、1 つの PDF にして保存します。
- **結合をオフにしたとき**は、ファイルごとに別々に保存します。ファイルごとに保存のダイアログが出ます（初期の名前は、元の名前に `_unlocked`・`_rotated` などを付けたもの）。

### 操作の順番
- 回転・結合・圧縮の順番は、**設定（⌘,）**で行をドラッグして変えられます。最初は「回転 → 結合 → 圧縮」です。
- 暗号化の解除はいつも最初です。

### 暗号化の解除
- オンにすると、制限のある PDF とパスワードが要る PDF の数を表示します。札にマウスを乗せると、何が禁止されているかが出ます。
- 保護を外す前に、「外して続ける」かどうかを確認します。
- パスワードが要る PDF は、処理の途中でその PDF の番になったときにパスワードを聞きます。入れたパスワードは、この Mac の中で処理に使うだけです。保存も送信もしません。
- 保存する PDF が本当に暗号化されていないかを、アプリが確かめてから保存します。
- 解除も結合もしないで回転や圧縮だけをしたときは、制限を付けたまま保存します（黙って外すことはしません）。
- **自分が権利を持つ書類にだけ使ってください。** 他人の書類や、制限を外すことが許されていない書類には使わないでください。

### 回転
- 「ページを見て回す…」を押すと、入れた PDF のページがすべて並びます。
- ページをクリックするたびに右へ 90° 回ります。右クリックすると、左回り・180°・元に戻すを選べます。
- 上の「すべて左に 90°」「すべて右に 90°」で全ページまとめて回せます。「すべて元に戻す」で最初の向きに戻ります。
- 開くのにパスワードが要る PDF は、ページを表示できないので回せません。

### 結合
- 左の並びの上から順に、1 つにまとめます。
- **しおり（目次）と、PDF の中のページへのリンクは、結合すると消えます**。Web ページへのリンクは残ります。しおりのある PDF を入れると、そのことを知らせます。

### 圧縮
- **構造の圧縮**（最初からオン）: PDF の中の部品をまとめて圧縮し直します。**見た目は一切変わりません**。
- **解像度**: 選んだ dpi（300・200・150・100・72）より細かい画像だけを縮めます。それより粗い画像には触りません。
- **JPEG の画質**: 写真やカラーのスキャンのような JPEG の画像を、選んだ画質（高・中・低・最低）で保存し直します。
- **図の線を減らす**（matplotlib などで作ったグラフ向け）: 補助グリッド線・補助目盛を消す、曲線の点を間引く、から選べます。オンにすると、減らせる数を先に表示します。どれも最初はオフです。
- PDF を入れると、大きさの内訳（画像・フォント・その他）と、圧縮したあとの**目安**を表示します。目安は見積もりなので、正確な数字は **試算する** で出します（実際に圧縮して大きさを測り、作った PDF はすぐ消します）。
- **目標**に提出先の大きさの上限（MB）を入れると、収まりそうなら緑、超えそうなら赤で示します。
- 圧縮したら、何をしたか（画像をいくつ縮めたかなど）を表示します。元より大きくなったときは、そのことを知らせます。
- パスワードが要る PDF は、解除するまで中を見られないので、内訳・目安・試算には入りません（圧縮そのものは行います）。

### 保存名の文字数
- 保存名の横に文字数（`.pdf` を含む）が出ます。「上限」に提出先の決まり（例：50 文字以下）を入れておくと、超えたときに赤字になります。

## プライバシー

- このアプリはインターネットに接続しません。PDF もパスワードも、外に送ることはありません。
- 処理には、アプリの中に入っている [qpdf](https://qpdf.sourceforge.io/) と、macOS に最初から入っている部品だけを使います。

## 開発者向け

必要なもの：

- Xcode 27 以降
- Homebrew の qpdf（`brew install qpdf`）。ビルドのたびに .app に同梱します

`LocalPDFTools.xcodeproj` を開いて ⌘R で起動、⌘U で検査（テスト）が走ります。
コードの構成は [`Sources/README.md`](Sources/README.md) にあります。

配布用の zip を作るには：

```
scripts/make_app.sh
```

`build/LocalPDFTools.app` と `build/LocalPDFTools-<バージョン>.zip` ができます。
バージョン番号は Xcode のプロジェクトの設定（MARKETING_VERSION）で決まります。
